# Учёт визитов бара — Telegram-бот + мини-приложение

Механика:
1. Официант (или админ) в админке генерирует QR (можно на смену/день или бессрочный).
2. Гость сканирует QR камерой телефона → открывается Telegram → бот.
   Если гость новый — просит поделиться контактом (имя+телефон подтягиваются
   из Telegram автоматически). Визит фиксируется сразу после этого.
3. Гость смотрит свою историю командой `/history` в боте или в мини-приложении
   (кнопка внутри бота) — видит **только свои** визиты.
4. Админ заходит в `/admin.html` по паролю и видит все визиты всех гостей,
   а также может сгенерировать новый QR-код.

Всё бесплатно: Telegram Bot API бесплатен всегда, Supabase и Railway/Render
имеют бесплатный тариф, которого с большим запасом хватит для одного бара.

## Шаг 1. Создать бота

1. В Telegram напишите **@BotFather** → `/newbot`.
2. Придумайте имя и юзернейм (должен заканчиваться на `bot`).
3. BotFather выдаст **токен** — сохраните его, это `BOT_TOKEN`.
4. Юзернейм бота (без `@`) — это `BOT_USERNAME`.

## Шаг 2. Создать базу данных (Supabase, бесплатно)

3. Вставьте туда содержимое файла `schema.sql` из этого проекта → Run.

## Шаг 3. Задать первого админа

В таблице `staff` (через Supabase → Table Editor) это необязательно для MVP —
вход в админку идёт по паролю (`ADMIN_PASSWORD` в `.env`), а не по Telegram-аккаунту.
Просто задайте свой пароль в `.env`.

## Шаг 4. Развернуть сервер (Railway, бесплатно)

1. Зарегистрируйтесь на https://railway.app (можно через GitHub).
2. Загрузите этот проект к себе на GitHub (создайте новый репозиторий и
   запушьте туда папку целиком), затем в Railway: **New Project → Deploy from GitHub repo**.
   (Вариант без GitHub: Railway также поддерживает `railway up` из CLI прямо из папки.)
3. В настройках проекта Railway → **Variables** добавьте все переменные
   из `.env.example` со своими значениями:
   - `BOT_TOKEN`
   - `BOT_USERNAME`
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_KEY`
   - `ADMIN_PASSWORD`
   - `SESSION_SECRET` (любая случайная строка)
   - `PUBLIC_URL` — заполните **после** первого деплоя, когда Railway выдаст
     домен (например `https://bar-checkin.up.railway.app`), затем передеплойте.
4. Railway сам определит `npm start` и запустит сервис.

## Шаг 5. Подключить мини-приложение к боту (необязательно, но удобно)

В @BotFather: `/mybots` → выберите бота → **Bot Settings → Menu Button**
→ укажите URL: `https://ваш-домен/app.html`.
Теперь у гостя в чате с ботом снизу будет кнопка, открывающая красивый
список визитов вместо текстовой команды `/history`.

## Как пользоваться каждый день

- **Официант/админ**: открывает `https://ваш-домен/admin.html`, вводит пароль,
  жмёт «Создать QR» (можно указать срок действия в часах — например 12,
  чтобы код был одноразовый на смену) → показывает QR-код с экрана гостю
  или распечатывает.
- **Гость**: сканирует QR камерой телефона → попадает в Telegram → визит
  фиксируется автоматически (в первый раз — попросит поделиться контактом).
- **Админ**: та же страница `/admin.html`, ниже — таблица всех визитов всех
  гостей с именем, телефоном и датой.
